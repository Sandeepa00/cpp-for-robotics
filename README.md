## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Sandeepa00/cpp-for-robotics.git
cd cpp-for-robotics
```

### 2. Install the C++ compiler

On Ubuntu:

```bash
sudo apt update
sudo apt install g++
```

Check the installation:

```bash
g++ --version
```

### 3. Compile a program

For example:

```bash
g++ -std=c++17 -Wall -Wextra class01_hello_world/class01_hello_world.cpp -o hello
```

### 4. Run the program

```bash
./hello
```

You can compile and run other `.cpp` files by replacing the source file path and executable name.
